# T2-50 地区回退匹配与来源标注

## 这一项要做什么

在 `app/knowledge/region.py` 中实现地区回退匹配：给定农户所在行政区编码，构造一条从县级到全国的有序回退链，逐级检索，某一级召回非空即停止，并把**实际命中的级别**写回 `EvidenceItem.region_scope` 与 `EvidenceSet.region_level_actual`。它是产品说明书 4.1.2 功能点 1"缺失时按上一级行政区回退并在界面明示"在检索侧的落地。

回退不是"查不到就随便给一条"，而是"逐级放宽，并在结果里留下足迹"，让界面能准确标注"当前按 XX 市通用农时提示"。

## 实现要点

### 回退链的构造

```python
class RegionMatcher:
    """地区回退匹配。构造回退链并逐级检索，保留实际命中级。"""

    def build_chain(self, region_code: str | None) -> list[tuple[str, str]]:
        """返回 (行政级别, 编码) 的有序回退链，从县级到全国。

        级别取值: county / city / province / national。
        """
        if not region_code:
            return [("national", NATIONAL_CODE)]
        chain: list[tuple[str, str]] = []
        code = region_code
        for level in ("county", "city", "province"):
            if len(code) >= LEVEL_LENGTH[level]:
                chain.append((level, code[: LEVEL_LENGTH[level]]))
        chain.append(("national", NATIONAL_CODE))
        return _dedupe_chain(chain)

    async def search_with_fallback(self, query: KnowledgeQuery) -> RegionSearchResult:
        """逐级检索，某级非空即停止。返回证据、实际命中级与尝试链。"""
        chain = self.build_chain(query.region_code)
        attempted: list[str] = []
        for level, code in chain:
            attempted.append(f"{level}:{code}")
            scoped = query.model_copy(update={"region_code": code})
            items = await self._repo.search(scoped)
            if items:
                return RegionSearchResult(items=self._stamp(items, level, code),
                    region_level_actual=level, fallback_chain=attempted)
        return RegionSearchResult(items=[], region_level_actual="none", fallback_chain=attempted)
```

`build_chain` 用编码前缀推导上级，而不是查表。中国行政区划编码是层级前缀编码：县级六位码的前两位是省、前四位是市。因此给定 `330100`（杭州市）能直接推出 `330000`（浙江省）；给定 `330102`（某区）能推出 `330100`（杭州市）与 `330000`。前缀推导避免为每个查询都做一次字典查找，也让回退链的构造是纯函数、可离线测试。字典表只用于把编码翻译成展示名（"杭州市"），不参与回退链构造。

`_dedupe_chain` 处理编码过短或重复的情况：当农户只填到市级（`330000`）时，县级前缀推导出的 `330000` 与市级相同，去重后只保留一条。`LEVEL_LENGTH` 定义三级编码长度（`county=6`、`city=4`、`province=2`）。

全国兜底码用 `000000`，与 T2-48 中未声明地区条目自动挂载的 `region_code` 一致。回退链最后一级永远是全国，保证任何查询都有兜底路径。

### 逐级检索与命中标注

```python
    def _stamp(self, items: list[EvidenceItem], level: str, code: str) -> list[EvidenceItem]:
        """把实际命中的行政级别写回每条证据的 region_scope。"""
        return [item.model_copy(update={"region_scope": f"{level}:{code}"}) for item in items]
```

`region_scope` 写成 `"county:330102"` 这样的带级别前缀形式，而不是只写编码。原因是展示层要据此生成"当前按 XX 市通用农时提示"，只给编码还需再查一次级别，且编码本身不携带级别信息（六位码只有在知道是县还是市时才能正确解读）。带级别前缀让标注信息自包含。

回退的判定循环放在本项，而不是检索实现内部。理由与 T2-18 的实现保持一致：检索实现接收单一地区编码并返回该级的召回，回退是"哪一级够用"的决策，属于地区匹配职责。这样 T2-49 的 `search` 保持"一个查询一个地区"的单一语义，便于单测。

### 实际命中级与展示标注

```python
@dataclass(slots=True)
class RegionSearchResult:
    """一次带回退的检索结果。"""
    items: list[EvidenceItem]
    region_level_actual: Literal["county", "city", "province", "national", "none"]
    fallback_chain: list[str]
    def display_note(self, region_name: str) -> str | None:
        """生成界面的地区标注语。县级命中时不需要标注。"""
        if self.region_level_actual in ("county", "none"):
            return None
        labels = {"city": "市", "province": "省", "national": "全国"}
        return f"当前按{region_name}通用提示"
```

`display_note` 不直接拼接"XX 市"字符串，而是返回标注键与级别，具体文案在展示层组装。原因是文案要过 `colloquial_map`（"市"在口语里可能是"我们这儿"），且展示层需要统一控制字数上限（适老化要求）。回退匹配只负责给出级别事实，不负责最终措辞。

`fallback_chain` 保留完整尝试路径（如 `["county:330102", "city:330100", "province:330000"]`），写入 `EvidenceSet.fallback_chain`。它有两个用途：界面在命中县级时也能展示"曾尝试的级别"，以及线上排查"为什么这条查询退到了省级"。全量保留而非只留终点，是因为排查时最想知道的是"哪一级开始命中"。

### county 命中不标注

只有当回退到市级及以上时才生成标注。县级命中说明农户所在地有专属条目，界面无需额外说明；若这种情况也标注"当前按 XX 县提示"，会给农户造成"数据不全"的错觉，反而降低信任。这条规则与产品说明书 4.1.2 的表述一致：回退发生时才有必要明示。

### 无编码时的行为

农户档案未填地区（`region_code=None`）时，回退链只有全国一级，检索只在全国兜底条目中召回。此时 `region_level_actual="national"`，`display_note` 返回"当前按全国通用提示"。这是"回退到最后一级"的边界情况，不是错误：地区缺失是常见状态，系统据此降低地区特异性表述而不阻断问诊。

### 与闸门 R-REGION 的衔接

`R-REGION` 规则（T2-40）要求"建议必须与农户所在地区、当前生育阶段匹配"。它读取本项产出的 `region_level_actual`：若实际为 `national` 且处方给出了地区特异建议（如某地特有的防治窗口），判定为 `degrade`，提示农户该建议为通用口径。因此本项的级别标注不只是展示需要，也是闸门判定的输入。
