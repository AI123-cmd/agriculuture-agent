# T4-03 首页层级精简

## 这一项要做什么

把首页从"今日播报 + 快捷入口 + 环境摘要 + 底部四 Tab"的多并列结构，压缩为"一屏两件事"：能提问、能看今日提示，其余一律降级或收进"我的"。产品说明书 6.5 红线第 2 条写明"只放大字体而不减少页面层级与并列选择数量，属于无效改造"，判断标准是量化的——农户打开首页后需要做出的选择不超过两处。本项是适老化改造里唯一涉及 WXML 结构与信息架构的部分，做不到位则 T4-02 的字号上调反而会让页面更长、选择更多。

## 前置依赖

- T4-01 必须已提供公共类（`.card` / `.t-heading` / `.t-body` / `.t-caption` / `.tap-88` / `.btn-primary` / `.block`）与 `--space-block` 等间距 token。
- T3-08 的快照生成链路与 T3-10 的展示状态：首页展示的是"已生成且当日内有效的快照"，跨日弱化状态由后端字段给出，本项只负责展示，不改变生成时机（决策二：提示由农户手动更新）。
- T3-15 的处方卡台账与执行回执接口：勾选"已执行"与取消勾选走同一接口，本项需确认接口支持取消语义，若不支持则以 T3-15 为准补齐。
- 现有改造起点：`pages/index/index.wxml`（60 行，含 location-row、今日农事播报 card、quick-wrap 四项、环境摘要 card）、`pages/index/index.ts`（`functions` 四项、`envData` 四项、`onFuncTap` 的 switch 分支）、`pages/index/index.wxss`、`pages/mine/mine.wxml`（已有农户档案、咨询历史、关于我们、用户协议四个菜单项）、`app.json` 的 `tabBar.list`。
- 外部环境要求：微信开发者工具可编译，`wx.switchTab` 与 `wx.navigateTo` 目标页均存在。

## 实现要点

### 一、现状的问题在哪

`pages/index/index.wxml` 的内容区由四块并列组成：`location-row`（1 个可点）、今日农事播报 `card`（含 N 条提示，每条 1 个勾选）、`quick-wrap`（4 个可点按钮：AI咨询、拍照识别、查看环境、农事管理）、环境摘要 `card`（4 个并列 `env-item`：温度、湿度、土壤、光照）。加上底部四个 Tab，一屏内可点元素数量为 `1 + N + 4 + 0 + 4`。这些元素层级相同、视觉权重相近，农户需要先判断"我该点哪个"，这正是产品说明书 1.2 表格里"适老化被简化为放大字体"一行所指的现状：放大字号后页面更长、选择更多。

`quick-wrap` 的四个入口尤其成问题：AI咨询与底部"咨询" Tab 重复，农事管理与"我的"里的农户档案重复，查看环境与底部"环境" Tab 重复，只有拍照识别是独立能力，而它本质是提问的一种输入方式。

### 二、目标结构

改造后首页内容区从上到下分四层，只有两个核心动作。

第一层，对象与地点（只读 + 一个附属入口）。保留顶部 `header` 的作物与农户名，保留 `location-row` 的地点名与"设置"。地点设置属于账号级附属操作，不参与核心动作计数，但必须从"一屏内并列的主入口"里降权：把右侧的"设置 ›"改为与地点名同行的小字，且不使用按钮底色。

第二层，今日提示模块（核心动作一：查看今日提示）。`card-title` 保留"今日农事播报"，提示条目沿用五段式与执行勾选，底部固定一行"更新时间 + 更新提示按钮"，按钮用 `.btn-primary`（96rpx 高）。勾选与更新提示都是本模块内部操作，不作为导航分叉。

第三层，环境一行状态（只读）。把 `env-grid` 的四个并列 `env-item` 合并为一行：`公共天气 · 温度 26°C · 湿度 62%`，右侧标注来源（"公共天气"或"本地传感器"）。来源标注是产品说明书 8.2 交互说明第 2 点的要求。这一行**不做跳转**，点击无响应，从而不构成一个选择；想查看完整环境数据的农户从"我的"页进入。

第四层，核心动作二：提问。一个整宽的主按钮"我要提问"，用 `.btn-primary`，点击 `wx.switchTab` 到咨询页。

`quick-wrap` 的整体删除是这一步的关键判断：它看起来像"收敛到少数几个"，但只要保留三四个并列按钮，加上提示模块与提问按钮，一屏内的并列分叉就会超过两处。因此按 4.7.3"非高频功能统一收进我的"处理，四项的去向为：AI咨询并入提问按钮；拍照识别改为提问页内的附图入口（提问时选择拍照，不占首页位置）；查看环境收进"我的"页新增菜单项；农事管理即农户档案，已在"我的"页存在，直接删除首页入口。

### 三、"不超过两处"的计数口径与核验表

按附录 A13，计数口径是核心动作，即提问与查看今日提示，不含底部导航。施工时必须产出 `docs/ui/首页选择计数表.md`，把首页全部可点元素列出并逐条标注，格式如下：

| 可点元素 | 位置 | 是否计入两处 | 理由 |
| --- | --- | --- | --- |
| 我要提问 | 内容区主按钮 | 计入（1） | 核心动作，附录 A13 列举项 |
| 更新提示 | 提示模块底部 | 计入（2） | 查看今日提示的核心动作，A13 列举项 |
| 提示条目执行勾选 | 提示模块内部 | 不计入 | 模块内操作，不产生导航分叉 |
| 地点设置 | 顶部附属行 | 不计入 | 账号级设置，非流程动作 |
| 环境一行状态 | 内容区只读 | 不计入 | 不可点，无跳转 |
| 底部四 Tab | 固定底栏 | 不计入 | A13 明确排除底部导航 |

结论行必须写"计入两处，达标"。这张表是验收时的对照物，比任何描述都容易核对。

### 四、底部四 Tab 的处理

产品说明书 9.2 第 13 条把"底部四 Tab"列为信息密度来源，而附录 A13 又把底部导航排除在计数口径之外。两处看似冲突，实际口径是：Tab 不计入"两处"，但仍属于需要精简的密度来源。本项的处理是**保持四 Tab 不变，只消除内容区与 Tab 的重复**：内容区不再出现与 Tab 同义的入口（不设"查看环境"按钮、不设"AI咨询"按钮），Tab 成为环境与咨询的唯一二级入口。理由有二：一是 `app.json` 的 `tabBar.list` 改动会牵动页面路由与 `custom-tab-bar/index.ts` 的 `urls` 数组，属于结构性改动，8.2 线框图底部仍为四 Tab，未要求删除；二是删除环境 Tab 会使环境页失去常驻入口，而环境数据是产品说明书 4.4 的独立模块。

若产品在评审中确认要把环境并入"我的"、底部改为三 Tab，本项预留该分支：`app.json` 与 `custom-tab-bar/index.ts` 的改动量共约 5 行，可在不触及其他任务的前提下执行。这个判断需要产品确认，不自行决定。

### 五、环境一行状态的降级口径

环境四项（温度、湿度、土壤、光照）合并为一行后，信息并未丢失：数值仍在，只是不再以四个等权卡片呈现。取值来源与展示规则不变，仍调用 `getSummary`，字段映射为 `温度 {temperature}°C · 湿度 {humidity}% · 土壤 {soilStatus}`，光照因中文短语较长，移入环境页详情，首页一行只保留三项。数据不可用时显示"环境数据暂不可用"，不使用推测值（决策四与产品说明书 4.3.1 的红线一致）。这一行不设 `bindtap`，WXML 中不得出现 `hover-class` 或 `bindtap`，避免被计入可点元素。

### 六、提示模块的展示约束

提示模块保留五段式（`callout / fact / impact / action` 由 T3-07 生成），级别前置，行动句加粗。跨日弱化按 T3-10 的展示状态执行：当日快照正常显示，跨日快照按弱化样式显示且不显示"已执行"勾选。空状态必须给出可理解的文案与下一步动作（如"今天还没有提示，点下面的按钮生成"），不出现空白卡片。产品说明书 4.6 功能点 5 要求异常与降级也要给出农户能懂的原因，首页加载失败时展示"网络不太好，稍后再试"与重试按钮，不显示错误码。

### 七、与语音朗读的衔接

首页提示模块是 T4-04 语音朗读的主要对象。本项需在提示条目上预留朗读触发点（每条提示右侧一个 `.tap-88` 的朗读按钮位），但朗读能力本身由 T4-04 实现。为保证两任务不冲突，本项只定义按钮的容器与类名（`.tip-read-btn` + `.tap-88`），不实现点击行为。这一预留不增加首页的"选择"计数，因为朗读属于提示阅读的辅助动作，与执行勾选同级。

## 验收标准

- `node tests/ui/test_home_choices.mjs` 通过：脚本解析 `pages/index/index.wxml`，统计内容区（`header` 与 `custom-tab-bar` 之外）的可点元素，断言计入 A13 口径的条数为 2，输出 `home choices: 2 (ask, view-tips) - pass`。
- 反向验证：在 `index.wxml` 中恢复一个 `quick-item` 按钮后重跑脚本，断言失败并提示"expected 2, got 3"；删除后恢复通过。
- `grep -n "bindtap" miniprogram/pages/index/index.wxml` 的结果中，内容区仅剩提问按钮、更新提示、提示勾选、地点设置四处，且无任何指向 `pages/env/env` 的跳转。
- `grep -n "env-grid\|env-item\|quick-wrap\|quick-item" miniprogram/pages/index/index.wxml miniprogram/pages/index/index.wxss` 无输出，证明并列卡片与快捷入口已彻底移除。
- `docs/ui/首页选择计数表.md` 存在，表格含全部可点元素与"计入/不计入"标注，结论行为"计入两处，达标"。
- 微信开发者工具中打开首页，一屏内（iPhone SE 尺寸 375×667）不滚动即可看到提示模块与提问按钮；环境为一行文字，点击无跳转。
- "我的"页新增"环境数据"菜单项，点击可进入环境页并正常返回；环境页在首页无入口的情况下仍可达。
- 提示模块空状态与网络异常状态各展示一次，均给出可读文案与下一步动作，无空白卡片、无错误码。
- 跨日快照（把系统日期改到次日）显示为弱化样式且不显示执行勾选，当日快照可勾选且可取消。
