# 农事播报助手 · 调研问题清单

> 说明：本文档只汇总「待调研的问题」，不给出答案。问题围绕四个主题展开，并结合作品「新域农力 · AI 农事播报助手」当前代码与产品方案补充了产品侧待澄清项。每一条均为编号问题，供后续调研逐条核实。

---

## 〇、产品背景（产品要解决什么）

新域农力是一款面向农户的微信小程序 AI Agent，核心链路为：

> 环境感知（传感器/天气）→ 作物入口 → 自然语言对话 → 用户画像 → 规则优先的智能播报 → 农业 AI 兜底 → 简洁卡片输出。

- 目标用户：普通农户、规模化种植户、农业合作社、农技推广人员。
- 核心要解决的问题：降低农业知识获取门槛、病虫害/农事决策依赖经验、环境风险响应慢、服务难个性化。
- 当前代码已实现：水稻、烟草、通用三类作物专家模型；诊断/种植/气象/知识/播报多 Skill 路由；`collect_symptoms` + `collect_management` 多轮追问闭环；农户档案 + 画像 + 记忆；传感器（空气/土壤温湿度、光照、pH/EC）+ 天气 + 阈值规则播报。

理解以上产品边界，有助于判断下列问题中哪些是「必须调研」、哪些是「产品已覆盖、待验证」。

## 一、不同作物、不同角色用户「最常问的问题」

### 1.1 按用户角色拆解

- **Q1.1.1** 普通农户在农业生产中最高频、最关心的问题分别是什么？其提问的颗粒度、口语化程度、决策诉求有何特征？
- **Q1.1.2** 规模化种植户 / 家庭农场主最常问的问题与普通农户有何差异（是否更关注成本、产量、地块管理、用工）？
- **Q1.1.3** 农业合作社 / 基地管理人员最常问的问题是什么（是否更关注多农户多地块统计、台账、标准化管理、产销对接）？
- **Q1.1.4** 农技推广人员在使用该类产品时最常问/最需要的问题是什么（是否更关注诊断依据、知识库权威性、服务效率）？

### 1.2 按作物与生育期拆解

- **Q1.2.1** 每种目标作物（水稻、烟草、玉米、小麦、辣椒、果树、蔬菜大棚、棉花等）在各自生育周期各阶段（播种、苗期、生长期、抽穗/开花、结果/收获）最常被问的问题分别有哪些？
- **Q1.2.2** 水稻的高频问题是否集中在稻飞虱、稻瘟病、纹枯病、水肥管理等方面？具体典型问法是什么？
- **Q1.2.3** 烟草的高频问题集中在哪些环节（育苗、移栽、病虫害、烘烤、分级）？典型问法是什么？

### 1.3 按问题类型拆解

- **Q1.3.1** 病虫害诊断类问题在不同作物上的高频表述是什么（如"叶子发黄""长斑""有虫子"等口语化描述如何映射到标准症状）？
- **Q1.3.2** 水肥管理类问题（何时施肥、追多少、何时灌排、是否缺肥）的高频问法有哪些？
- **Q1.3.3** 农事决策类问题（"现在该播种/打药/收获吗"）的典型表述与决策依据是什么？
- **Q1.3.4** 天气与环境类问题（高温、低温、干旱、连阴雨）用户是如何提问的？

### 1.4 按用户经验水平拆解

- **Q1.4.1** 经验水平不同（新手 vs 经验老农）的提问深度、对建议颗粒度的需求有何差异？
- **Q1.4.2** 哪些高频问题可被标准知识库 / FAQ 直接覆盖，哪些必须依赖实时环境数据（传感器/天气）才能回答？

## 二、作物区播报系统的流程

### 2.1 「播报什么」

- **Q2.1.1** 一次合格的农事播报应包含哪几类内容（气象风险预警、病虫害气象风险、土壤墒情、关键农事提醒等）？各类的边界与优先级如何？
- **Q2.1.2** 播报内容应覆盖哪些风险场景（高温热害、低温冻害、干旱、渍涝、连阴雨、大风、干热风、霜冻等）？不同作物对应哪些风险？

### 2.2 「根据什么播报」

- **Q2.2.1** 播报的数据源有哪些（传感器实时数据、天气预报、物候期/农事历、作物生育期、用户画像）？各自权重与优先级如何设定？
- **Q2.2.2** 规则的触发阈值（高温/低温/土壤干旱/高湿/降雨/大风）应依据什么标准设定（是否为气象行业标准 QX/T 系列）？不同作物、不同地区是否需要差异化？
- **Q2.2.3** 物候期/农事历如何与实时环境数据结合，形成"阶段对应"的农事提醒？

### 2.3 「播报的触发与呈现」

- **Q2.3.1** 播报的触发时机与频率是什么（用户打开首页实时生成 / 每日定时预生成 / 阈值触发 / 主动订阅推送）？各时机的适用场景？
- **Q2.3.2** 播报的呈现形式（结构化卡片：结论/要点/来源/下一步）如何确保农户"易读、可信、可执行"？
- **Q2.3.3** 主动推送（微信订阅消息）的流程与合规边界是什么，如何避免打扰用户、如何引导订阅与退订？

### 2.4 「播报有什么作用」

- **Q2.4.1** 播报对农户的生产决策价值（及时避险、省力）具体体现在哪些环节？
- **Q2.4.2** 播报对管理人员/平台的省工价值、用户粘性价值分别是什么？

### 2.5 降级与兜底

- **Q2.5.1** 无传感器数据时如何兜底（天气 API / 区域数据 / mock）？兜底播报的可信度如何保证、如何标注来源？

## 三、农技人员解决农民问题的流程

- **Q3.1** 农技人员通常通过哪些渠道接到农户问题（常态坐诊 / 田间巡诊 / 线上问诊 / 按需会诊）？接诊时首先要明确哪些基础信息（作物、地点、季节与生育期、核心诉求）？
- **Q3.2** 诊断前需要采集哪三类信息（症状表现 + 种植管理过程 + 环境与历史）？每类分别包含哪些具体内容？
- **Q3.3** "望闻问切检"式症状观察具体包含哪些动作（看长势、看病部、闻气味、切开检根茎、采样送检等）？田间分布形态（点状/条带/全田均匀）如何帮助判因？
- **Q3.4** "管理追溯"要追问哪些变量（前茬作物、品种、种子来源、水肥、打药、浇灌、历史病害、当地气候与习惯）？
- **Q3.5** 从"症状 + 管理 + 环境"到综合诊断的推理链路是什么？如何区分生理性 / 侵染性 / 药害 / 环境胁迫等病因类别？
- **Q3.6** "开处方/给建议"要落到哪些可执行层面（农事措施、精准用药如药剂+倍数+水量+喷法、安全用药规范）？
- **Q3.7** 落实指导与回访跟踪（台账、定期回访、按效果调整、疑难提级转专家）的完整闭环是如何运转的？
- **Q3.8** 这套真人流程映射到 AI 咨询系统时，每个环节 AI 能承接什么、边界在哪（哪些必须线下采样检测或人工复核）？

## 四、传感器等感知器件在现代农业中的作用与结合方式

- **Q4.1** 现代农业中传感器（空气/土壤温湿度、土壤含水率、光照、pH/EC、降雨、风速等）最核心的作用是什么（环境感知 → 风险识别 → 精准决策）？
- **Q4.2** 感知数据如何与农事决策结合——是"规则阈值直出提醒"还是"AI 综合判断"？两者应如何分工、何时切换？
- **Q4.3** 传感器数据如何与作物生育期、物候期、农事历结合，形成精准的阶段性农事建议？
- **Q4.4** 传感器缺失/故障/数据异常时如何降级（天气 API、区域数据、历史统计）？如何保证降级后的可信度？
- **Q4.5** 感知数据如何与用户画像（作物、地块、经验水平、关注点）结合，实现"千人千面"的个性化播报与问答？
- **Q4.6** "传感器 → 网关 → 后端 → 前端"的数据链路如何设计？采样频率、异常值检测、设备标定与数据质量如何保证？
- **Q4.7** 感知数据如何沉淀为长期农情数据资产，支撑后续的智能化升级（趋势预测、区域病害预警）？
