# 首页选择计数表（T4-03）

依据：产品说明书 4.7.3 功能点 1、8.2 交互说明第 7 点、附录 A13。
计数口径为**核心动作**——农户打开首页后需要做出的选择不超过两处，不含底部导航。

## 全部可点元素

| 可点元素 | 位置 | 是否计入两处 | 理由 |
| --- | --- | --- | --- |
| 我要提问 | 内容区主按钮 | 计入（1） | 核心动作，附录 A13 列举项 |
| 更新提示 | 提示模块底部 | 计入（2） | 查看今日提示的核心动作，A13 列举项 |
| 提示条目执行勾选 | 提示模块内部 | 不计入 | 模块内操作，不产生导航分叉 |
| 提示条目朗读（读） | 提示模块内部 | 不计入 | 朗读属提示阅读的辅助动作，与执行勾选同级（T4-03 §七、T4-04） |
| 地点设置 | 顶部附属行 | 不计入 | 账号级设置，非流程动作 |
| 环境一行状态 | 内容区只读 | 不计入 | 不可点，无跳转 |
| 底部四 Tab | 固定底栏 | 不计入 | A13 明确排除底部导航 |

## 结论

**计入两处，达标。**

## 施工对照

- 已删除的并列分叉：`quick-wrap`（AI咨询、拍照识别、查看环境、农事管理四项）与 `env-grid`（温度、湿度、土壤、光照四格）。
- 四项去向：AI咨询并入「我要提问」；拍照识别改为提问页内附图入口；查看环境收进「我的」页新增菜单项；农事管理即农户档案，已在「我的」页存在。
- 环境摘要降级为一行只读状态（`公共天气 · 温度 26°C · 湿度 62%`），标注来源，不设 `bindtap`/`hover-class`。
- 底部四 Tab 保持不变，只消除内容区与 Tab 的重复入口。
