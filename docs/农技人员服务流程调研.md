# 农技人员为农户提供诊断建议的典型业务流程调研

## 摘要

农技人员（农艺师、植保专家、科技特派员、基层农技推广员）为农户提供建议，本质上是一套**「接诊 → 观察 → 追问 → 诊断 → 开方 → 落实 → 回访」的闭环**，并非"一问一答"。调研的权威来源（各级农业农村厅、农技推广中心、专业农业期刊）一致显示，这条流程可以归纳为八个步骤，背后有两条贯穿始终的主线：

1. **先取证、后判断**：诊断前必须同时拿到「症状表现 + 种植管理过程 + 环境与历史」三类信息，任何一类缺失都可能导致误判。[8][10]
2. **建议要给到"能落地"的程度**：不只说"该防治"，而要具体到农事操作、药剂名称、浓度倍数、喷施方式，并遵守安全用药规范，最后还要回访跟踪、按效果调整。[11][12][13]

对正在设计的 AI 咨询流程而言，最直接的对标案例是重庆市巴南区推广的「AI 庄稼医院」：**AI 先做初诊 → 专家复核确认 → 疑难提级诊断 → 输出用药方案 → 推荐合规农资点**，即"识病、开方、买药"一站式。[2] 海外同类产品 CropRx 也采用「AI 诊断 + 置信度分级 + 低置信度转人工 + 第 7 天回访」的相同结构。[14]

## 一、农技服务的几种典型形态

农技人员接触农户的渠道，决定了"建议流程"的起点，主要有四类：

| 形态 | 说明 | 来源 |
|---|---|---|
| 常态坐诊 | 在乡镇农技站固定值守，面对面解答病虫害、施肥、田间管理问题 | [7] |
| 田间巡诊 | 农技员主动下沉到田间地头，实地查看苗情、墒情、病虫害 | [1][7] |
| 按需会诊 | 疑难病情组织多级专家集中研判、提级诊断 | [2][7] |
| 线上问诊 | 微信群、小程序提交图片 + 文字描述，专家远程开方 | [2][3] |

其中广南县的实践把四者整合为「**常态坐诊、田间巡诊、按需会诊、线上问诊**」的"四维服务模式"，是基层农技服务的一个典型范式。[7]

在组织层面，主流做法是"包村联户"：每名农技员定向包联 1 个以上行政村、联系若干生产大户或示范户，签订结对服务协议，明确服务内容与职责。[16][17]

## 二、一次完整「诊断—建议」的八步流程

以下是农技人员处理单个农户问题的典型顺序。对应流程可概括为：

```
接诊受理 → 症状观察（望） → 管理追溯（问） → 现场勘查/采样（闻观切检）
        → 综合诊断 → 开处方/给建议 → 落实指导 → 回访跟踪（疑难提级）
```

### 步骤 0：接诊受理

农技人员通过坐诊、巡诊或线上渠道接到农户求助，先明确"作物、地点、当前季节/生长阶段、农户最关心的问题"这几项基础信息，再进入诊断。[7]

例如商丘市农技专班收到农户诉求后"直奔田间地头，第一时间为农户排忧解难"，说明从接诊到现场响应是有明确时效要求的。[1]

### 步骤 1：望——症状观察

诊断第一步是整体观察，核心方法可概括为"八看"：看植株长势、看田间分布、看发病部位、看病状与颜色、看群体表现等。[9] 其中田间分布形态信息量很大：

- **点状分布** → 多提示虫传病害；
- **条带状分布** → 可能是流水传播或施肥不当；
- **全田均匀发病** → 大概率是气候异常或药害。[9]

同时要判断"整体发生还是零星发生"，以区分**生理性病害**（缺素、环境胁迫）与**侵染性病害**（病原物引起）。[8]

### 步骤 2：问——管理追溯（"六问"）

只看症状不够，必须追问种植管理过程。典型要了解的信息包括：**前茬作物、种子来源、品种名称、施肥管理、喷施药物、浇水情况、种植历史、历年病害与当地气候**。[4][9]

商丘农技专班的现场做法印证了这一点：专家"逐一摸清玉米播种时间、水肥浇灌、前期打药等田间管理细节"。[1] 贵州农技人员则是"详细询问小麦的前茬作物和种子来源、品种名称、施肥管理、喷施药物等有关情况，并结合当地种植习惯、历年病害及气候综合分析"。[4]

### 步骤 3：闻、观、切、检——现场勘查与采样

在观察与询问基础上，进一步做接触式检查：

- **闻**：闻病部气味，辅助判断（如某些病害有特殊气味）[4]；
- **观**：对发病部位的病变内外症状做详细观察 [10]；
- **切**：切开病部、检查根茎内部；
- **检**：必要时采集病株标样、根际土壤、根系及昆虫/线虫等，送实验室检验。[10]

规范化程序要求"对病植物样本作全面观察，尤其是发病部位内外症状"，并"尽可能到发病现场勘查，了解发病历史、发生特点、品种与生态环境"。[10]

### 步骤 4：综合诊断

把「症状 + 管理 + 环境/历史」三类信息综合，定位真正的症结。典型结论不是简单一句"生病了"，而是明确诱因，例如：

- 崇左案例：通过土壤检测、植株诊断，找出"土壤板结、养分不足"的症结，对症制定"配方肥施用 + 土壤改良"方案。[5]
- 旌德县案例：现场研判后指出"地块积水饱和度超标、种子长期浸水无法透气生根，是催芽失败的核心原因"。[如旌德案例]

诊断的关键价值在于**区分病因类别**（生理性 / 侵染性 / 药害 / 环境胁迫），因为不同病因的处置方向完全不同。[8][10]

### 步骤 5：开处方 / 给建议

诊断明确后，建议必须落到可执行的具体操作，通常包含三部分：

1. **农事措施**：如清沟沥水、排涝降湿、适时补播、追肥促弱、疏通田间三沟等。[3][19]
2. **精准用药**：给出具体药剂名称、稀释倍数、兑水量、喷施部位。例如"70% 吡虫啉 1000—1500 倍、每亩兑水 30kg、喷匀叶片正反面"。[11]
3. **安全用药规范**（这是硬约束，不可省略）：

| 规范 | 内容 |
|---|---|
| 轮换用药 | 单一农药品种（有效成分）每生长季使用不超过 2 次，交替不同作用机理药剂，延缓抗药性 [12] |
| 混配预试验 | 混配前取少量药液混合静置 30 分钟，观察是否乳化破坏、絮结 [12] |
| 剂型适配 | 飞防优先选微乳剂、悬浮剂并配飞防助剂，避免药液漂移引发次生药害 [13] |
| 减量增效 | 优先生物农药与低毒高效药剂，讲究"傍晚打、喷头细、打到叶心" [13][15] |

### 步骤 6：落实指导

建议给出后，还要帮农户把方案落地：现场示范操作、开设田间课堂发放明白纸，以及**推荐合规的农资销售点**，实现"识病、开方、买药"一站式。[2][16]

### 步骤 7：回访跟踪（闭环）

这是流程中容易被忽略、但官方反复强调的一环：建立**服务台账、定期回访跟踪、按效果及时调整技术方案**，确保"问题反馈有解、技术落实到田、服务跟踪到人"。[5][6]

若效果不佳或属疑难病情，则**提级**：由镇街 → 区县 → 市级专家团队逐级深入诊断，最终形成权威结论。[2] 这一点在 AI 流程设计里对应"低置信度转人工/专家"的机制。

## 三、关键特征总结

| 维度 | 要点 |
|---|---|
| 诊断方法论 | "望、闻、问、观、切、检"六字 [8]；"八看 + 六问 + 十三查"口诀 [9] |
| 信息维度 | 症状表现 + 种植管理 + 环境与历史，三类缺一不可 [1][4][10] |
| 病因判断 | 必须区分生理性 / 侵染性 / 药害 / 环境胁迫 [8][10] |
| 处方质量 | 具体到药剂、倍数、水量、喷施方式 + 安全用药规范 [11][12][13] |
| 服务闭环 | 台账 + 定期回访 + 按效果调整 + 疑难提级 [5][6][2] |

## 四、对 AI 咨询流程设计的启示

把上述真人流程映射到 AI 咨询系统，可得到一张"人做的工作 → AI 如何承接、以及 AI 的边界"对照表：

| 真人流程环节 | AI 系统的承接方式 | 需注意的边界 |
|---|---|---|
| 接诊受理 | 明确作物/地点/生长阶段/诉求 | 依赖农户档案；缺档案需先引导补齐 |
| 望（症状观察） | 基于图片的视觉诊断 + 症状关键词 | 无图片时诊断置信度应显著下降 |
| 问（管理追溯） | 主动反问"前茬/品种/水肥/打药/历史" | 这正是现有农户档案 + 记忆功能要覆盖的字段 |
| 闻观切检 | 仅能靠图片 + 文字，无法真正"闻/切/检" | 明确声明能力边界，采样检测需线下 |
| 综合诊断 | 症状 + 画像 + 气候/历史 综合分类 | 区分病因类别，而非只给一个病名 |
| 开处方 | 结构化建议：农事措施 + 用药建议 | 用药必须带安全规范 + 免责 + 建议人工复核 |
| 落实指导 | 推荐合规农资点、给出操作步骤 | 涉及购买需明确非医疗/农药处方性质 |
| 回访跟踪 | 记忆功能 + 定时回访（可与现有记忆/定时任务结合） | 回访应是流程的一部分，而非一次性的 |
| 疑难提级 | 低置信度 → 转人工专家复核 | AI 的诊断结果应保留置信度并支持升级 [2][14] |

**核心启示**：AI 咨询流程不应设计成"用户问一句、AI 答一句"的静态问答，而应模仿真人以**多轮追问 + 结构化诊断 + 可落地处方 + 回访闭环**。其中"问（管理追溯）"这一环，恰好可以由本项目已有的**农户档案 + 记忆功能**来承载——档案提供静态字段（前茬、品种、水肥、施药历史），记忆功能提供跨会话的背景，这正是让 AI 回答更接近真人农技员的关键。

同时，"开处方"环节必须内置**安全用药规范与人工复核/免责机制**，这是真人流程里的硬约束，也是 AI 落地的合规底线。[12][13]
