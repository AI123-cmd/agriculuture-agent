## 时限规则

- **从"人工确认结论"落笔当天起算，3 个工作日内完成 `EvalCase` 补充。**
- `补充截止日` = 发现日期 + 3 个工作日（按真实工作日计算，跳过周六周日）。
- `状态` 只能取 `待确认 / 待补充 / 已补充 / 已否决` 之一。
- 超过截止日仍为 `待补充` 的条目，由 T6-11 的 CI 检查为**提示项**（提示而非阻断，
  因为人工确认可能耗时，但必须可见）。
- `已否决` 是必要状态：并非每个线上异常都该进评测集（可能是一次性配置错误）。
  否决必须写明理由，否则本表会退化成"只增不减的列表"，最终没人看。
